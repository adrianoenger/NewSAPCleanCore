# Navigation Views

The Results area exposes one synthesis page plus four presentation perspectives. They are not access roles.

## Dashboard Geral
Primary question: **What is the overall state of this Assessment?**

Default content:
- processing/result KPIs;
- Clean Core distribution;
- risk/impact summaries;
- critical applications/findings;
- links into each perspective.

## Executive View
Primary question: **Where are the major risks and decisions?**

Default content:
- risks;
- critical applications;
- macro recommendations;
- Clean Core distribution;
- suggested roadmap.

## Technical View
Primary question: **What exactly must be changed and where?**

Default content:
- object explorer;
- source/code;
- ATC and other findings;
- evidence;
- dependencies;
- remediation proposals and SAP technical guidance.

## Functional View
Primary question: **What does this custom code do for the business?**

Default content:
- business rules;
- processes;
- discovered applications;
- functional dependencies;
- evidence;
- validation/correction of AI interpretation.

The UI must distinguish AI-generated interpretation from user-validated or user-corrected information.

## Architecture View
Primary question: **How should this custom landscape evolve?**

Default content:
- application landscape;
- dependency graph;
- coupling patterns;
- SAP guidance;
- Clean Core patterns;
- modernization/extension paths.

## Cross-view continuity
Switching result views keeps the same Client/Assessment and preserves Copilot conversation. The center content, menu, suggested questions and default level of detail change.
