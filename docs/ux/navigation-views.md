# Navigation Views

The four views are presentation perspectives, not access roles.

## Executive
Primary question: **Where are the major risks and decisions?**

Default content:
- assessment KPIs;
- Clean Core recommendation distribution;
- business importance × technical risk matrix;
- applications requiring attention;
- macro insights and recommendation themes.

## Architecture & Clean Core
Primary question: **How should this custom landscape evolve?**

Default content:
- application landscape;
- dependency graph;
- Clean Core patterns;
- standard dependencies;
- SAP guidance;
- modernization/extension direction.

## Business & Rules
Primary question: **What does this custom code do for the business?**

Default content:
- business domains;
- discovered applications;
- business rules;
- rule evidence and related objects;
- functional explanations.

## Engineering & Code
Primary question: **What exactly must be changed and where?**

Default content:
- object explorer;
- findings and ATC;
- source explorer with Monaco;
- dependencies;
- evidence;
- SAP guidance and technical recommendation.

## Cross-view continuity
Switching views keeps the same Client/System/Assessment and preserves Copilot conversation. The center content, menu, suggested questions and default level of detail change.
