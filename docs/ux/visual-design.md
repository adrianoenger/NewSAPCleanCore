# Visual Design Direction

## Character
Modern intelligence workbench: dashboard + knowledge explorer + AI Copilot.

## Design principles
- high information clarity;
- progressive disclosure;
- strong drill-down from insight to evidence;
- restrained visual density;
- subtle motion;
- large usable tables and source views;
- visual distinction between customer evidence, ATC, SAP guidance and AI interpretation.

## Suggested frontend libraries
- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- TanStack Query + TanStack Table
- Recharts
- React Flow
- Monaco Editor
- Framer Motion
- Lucide Icons

## Accent
T-Systems magenta `#E20074` may be used as the principal accent, while severity and semantic states use independent conventional colors. Do not make the interface predominantly magenta.
