# User Journey

## Processing mode
1. Open application.
2. Select or create a Client.
3. Select or create an SAP System.
4. Create an Assessment.
5. Select the assessment source directory.
6. Validate discovered source structure.
7. Start pipeline.
8. Observe stage-by-stage progress.
9. Pause or resume as needed.
10. Retry failed items without restarting successful work.
11. When sufficient stages finish, enter navigation mode.

## Navigation mode
The user selects one of four perspectives at any time:
- **Executive** — macro risk, impact, applications and recommendations.
- **Architecture & Clean Core** — architecture, dependencies, Clean Core patterns and target directions.
- **Business & Rules** — applications, domains, processes and discovered business rules.
- **Engineering & Code** — SAP objects, findings, source, ATC, dependencies and remediation context.

The perspective is not an authorization profile. It only changes prioritization, language, menu and default visualizations.

## Universal exploration principle
**Explore visually. Ask naturally. Validate through evidence.**

The AI Copilot is always present on the right. It receives the current assessment, view, entity and source selection as context and may return navigable references to code, findings, rules, applications, dependencies or SAP guidance.
