# Functional Capabilities

## Core entities
Client → SAP System → Assessment → Source Files → SAP Objects → Evidence → Findings → Business Rules → Applications → Clean Core Assessments → Recommendations.

## Main capabilities
1. Manage multiple clients, SAP systems and assessments.
2. Select and scan a large local source directory.
3. Classify and fingerprint files for incremental reprocessing.
4. Parse SAP artifacts into a normalized object catalog.
5. Discover deterministic object dependencies.
6. Import and link ATC findings.
7. Detect additional deterministic technical findings.
8. Interpret SAP objects using LLMs.
9. Discover and consolidate business rules.
10. Discover functional applications from object clusters.
11. Retrieve SAP/ABAP guidance from MCP providers.
12. Produce evidence-based Clean Core risk and recommendation outputs.
13. Create embeddings for semantically meaningful entities.
14. Expose visual dashboards and drill-down explorers.
15. Allow contextual AI questions over SQL facts, semantic knowledge, source evidence and SAP MCP guidance.
16. Pause, resume, retry and recover long-running processing.
