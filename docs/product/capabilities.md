# Functional Capabilities

## Core entities
Client → Assessment → Source Files → SAP Objects → Evidence → ATC/Technical Findings → Business Rules → Applications → Clean Core Assessments → Recommendations.

`SAP source system` is Assessment metadata, not an independently managed entity.

## Main capabilities
1. Manage multiple clients and assessments.
2. List/filter all assessments from the application home.
3. Create a simple Client and create an Assessment linked to a Client.
4. Store SAP source system as Assessment metadata.
5. Explicitly select and scan a large local source directory; no default source path.
6. Classify and fingerprint files for incremental reprocessing.
7. Parse SAP artifacts into a normalized object catalog.
8. Import variable-layout `.xlsx` ATC reports, preserve raw evidence, map available fields dynamically and link findings to Assessment objects when possible.
9. Discover deterministic object dependencies and technical findings.
10. Run provider-agnostic AI processing using Bedrock or Azure AI Foundry adapters.
11. Discover and consolidate business rules.
12. Discover functional applications from object clusters.
13. Retrieve SAP/ABAP guidance from MCP providers.
14. Produce evidence-based Clean Core risk and recommendation outputs.
15. Create embeddings for semantically meaningful entities.
16. Show a preliminary KPI summary after processing.
17. Expose Dashboard Geral plus Executive, Technical, Functional and Architecture result views.
18. Allow contextual AI questions over SQL facts, semantic knowledge, source evidence and SAP MCP guidance.
19. Pause, resume, retry and recover long-running processing.
20. Keep the AI Copilot available on the right across the entire application.
