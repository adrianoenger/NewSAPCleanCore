# SPRINT-10 — SAP Knowledge MCP

## Goal
Enrich relevant findings and applications with SAP knowledge.

## Planned capabilities
- Implement SAPKnowledgeProvider abstraction.
- Connect configurable mcp-sap-docs and mcp-abap endpoints.
- Query only when relevant and cache/reuse guidance.
- Persist SAP documentation evidence with provider/reference provenance.
- Render SAP Guidance in finding/application detail.

## Demonstrable outcome
Open a relevant finding and see SAP/ABAP guidance retrieved through MCP with source/provider provenance.

## Minimal validation
- Primary user flow for this sprint works.
- Relevant smoke test(s) pass.
- Critical API/schema/domain contracts introduced by this sprint are validated.
- Do not add broad test coverage unrelated to the demonstrated capability.

## Completion criteria
- Planned capabilities implemented or explicitly deferred with rationale.
- Demonstrable outcome reproduced successfully.
- Progress/state files updated.
- Application remains runnable for the next sprint.
