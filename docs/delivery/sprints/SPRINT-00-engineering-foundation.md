# SPRINT-00 — Engineering Foundation

## Goal
Establish the runnable development foundation without implementing domain breadth.

## Planned capabilities
- Create repository/application structure, Dev Container and Docker Compose.
- Start PostgreSQL with pgvector and backend FastAPI.
- Establish SQLAlchemy + Alembic migration foundation for schema evolution.
- Create Electron + React + TypeScript shell using permanent three-panel layout placeholder.
- Expose backend `/health` and render connectivity state in UI.
- Add `.env.example`, ignore secrets, and document startup commands.
- Establish a minimal synthetic seed mechanism suitable for later demo entities without adding customer data.

## Demonstrable outcome
Open the desktop shell, confirm backend/database health and see left navigation, center workspace placeholder and right Copilot placeholder.

## Minimal validation
- Primary user flow for this sprint works.
- Relevant smoke test(s) pass.
- Critical API/schema/domain contracts introduced by this sprint are validated.
- Do not add broad test coverage unrelated to the demonstrated capability.

## Completion criteria
- Planned capabilities implemented or explicitly deferred with rationale.
- Demonstrable outcome reproduced successfully.
- Progress/state files updated.
- Sprint result can be generated by the canonical finish workflow.
- Application remains runnable for the next sprint.
