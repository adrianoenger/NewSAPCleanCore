# ADR-008 — Evidence-First Clean Core Analysis

**Status:** Accepted  
**Date:** 2026-09-23

## Decision
Persist facts and provenance separately from AI interpretation. Findings, rules and Clean Core recommendations must reference supporting evidence. AI output alone is not authoritative technical evidence.

## Consequence
Implementation and sprint acceptance criteria must remain consistent with this decision. Any future change requires updating or superseding this ADR.
