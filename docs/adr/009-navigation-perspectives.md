# ADR-009 — Four Navigation Perspectives

**Status:** Accepted  
**Date:** 2026-09-23

## Decision
Expose Executive, Architecture & Clean Core, Business & Rules, and Engineering & Code as selectable views over the same assessment. They are UX perspectives, not user roles or permissions.

## Consequence
Implementation and sprint acceptance criteria must remain consistent with this decision. Any future change requires updating or superseding this ADR.
