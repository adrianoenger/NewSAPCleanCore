# ADR-002 — Electron + React Desktop Shell

**Status:** Accepted  
**Date:** 2026-09-23

## Decision
Use Electron for native desktop/filesystem interaction and React for the reusable user interface. Keep Clean Core domain logic outside Electron/React and in the Python backend.

## Consequence
Implementation and sprint acceptance criteria must remain consistent with this decision. Any future change requires updating or superseding this ADR.
