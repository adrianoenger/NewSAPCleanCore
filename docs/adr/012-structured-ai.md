# ADR-012 — Structured and Validated AI Outputs

**Status:** Accepted  
**Date:** 2026-09-23

## Decision
Persistable AI capabilities return versioned structured outputs. Validate schema, evidence references and domain rules before persistence; allow insufficient-context results rather than forced conclusions.

## Consequence
Implementation and sprint acceptance criteria must remain consistent with this decision. Any future change requires updating or superseding this ADR.
