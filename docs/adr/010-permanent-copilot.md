# ADR-010 — Permanent Right-Side AI Copilot

**Status:** Accepted  
**Date:** 2026-09-23

## Decision
Keep the AI Copilot permanently mounted on the right side in all navigation views. It follows UI context, accepts added entities/source selections, and returns navigable references without automatically mutating assessment state.

## Consequence
Implementation and sprint acceptance criteria must remain consistent with this decision. Any future change requires updating or superseding this ADR.
