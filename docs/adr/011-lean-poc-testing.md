# ADR-011 — Lean PoC Testing Strategy

**Status:** Accepted  
**Date:** 2026-09-23

## Decision
Prioritize sprint velocity. Use smoke tests, critical contract tests, critical-flow tests and selected integration checks. Do not create tests merely to raise coverage or add production-grade test suites in this phase.

## Consequence
Implementation and sprint acceptance criteria must remain consistent with this decision. Any future change requires updating or superseding this ADR.
