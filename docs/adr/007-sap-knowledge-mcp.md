# ADR-007 — SAP Knowledge via MCP

**Status:** Accepted  
**Date:** 2026-09-23

## Decision
Use configurable `mcp-sap-docs` and `mcp-abap` providers through backend adapters. Prefer local Docker for controlled demonstrations; use contextual enrichment rather than indiscriminate per-object calls.

## Consequence
Implementation and sprint acceptance criteria must remain consistent with this decision. Any future change requires updating or superseding this ADR.
